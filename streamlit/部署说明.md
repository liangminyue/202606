# 部署说明：地贫输血疗效血红蛋白智能测算工具（Streamlit Web 应用）

本说明面向**将 `streamlit/` 文件夹直接部署到 Streamlit 官网（Streamlit Cloud）** 的场景。
该文件夹已**自包含**，无需本机任何额外文件即可上线。

---

## 一、文件夹结构

```
streamlit/
├── streamlit_app.py          # 应用主程序（入口）
├── requirements.txt          # 依赖清单（已锁定版本，与模型序列化版本一致）
├── models/                   # 模型与特征配置（必须随仓库一起提交）
│   ├── 梯度提升_best_model_R2_0.8775.pkl        # 训练好的模型（Pipeline）
│   └── 表16_被选中特征筛选的变量表.csv           # 特征名称与范围配置
└── 部署说明.md               # 本文件
```

> 应用会自动从 `streamlit/models/` 读取模型与特征表；若设置了环境变量
> `STREAMLIT_MODEL_DIR`，则优先使用该路径。

## 二、本地运行（可选，用于自测）

```bash
# 1. 创建并激活虚拟环境（Python 3.12）
python -m venv .venv
source .venv/Scripts/activate        # Windows-Git-Bash / Linux / macOS

# 2. 安装依赖
pip install -r streamlit/requirements.txt

# 3. 运行
streamlit run streamlit/streamlit_app.py
```

浏览器打开终端给出的本地地址（默认 http://localhost:8501）即可使用。

## 三、部署到 Streamlit Cloud（推荐方式：整库部署）

Streamlit Cloud 从 GitHub 拉取代码并自动安装依赖、启动应用。

### 步骤 1：推送到 GitHub

```bash
git add streamlit/ requirements.txt runtime.txt .gitignore
git commit -m "feat: 部署地贫输血疗效 Hb 测算 Streamlit 应用"
git push origin main
```

> 仓库根目录已提供 `requirements.txt`、`runtime.txt`、` .gitignore`，
> 这是 Streamlit Cloud **必须读取**的部署文件（Cloud 只认仓库根目录的依赖清单）。
> `.gitignore` 已排除本地大体积实验数据（`多次实验结果/` 等），不会误传。

### 步骤 2：在 Streamlit Cloud 新建应用

1. 打开 https://share.streamlit.io （或新版 https://streamlit.io/cloud ）。
2. 用 GitHub 账号登录并 **Authorize**（授权访问你的仓库）。
3. 点击 **New app** / **创建应用**。
4. 选择刚才推送的 **Repository**。
5. **Main file path** 填写：
   ```
   streamlit/streamlit_app.py
   ```
6. **Python version** 选 **3.12**（仓库根 `runtime.txt` 已锁定，通常自动识别）。
7. 点击 **Deploy!**。

### 步骤 3：等待部署完成

- Streamlit Cloud 会读取仓库根的 `requirements.txt` 安装依赖
  （含 `scikit-learn==1.3.2` 等），随后启动 `streamlit/streamlit_app.py`。
- 约 1–3 分钟后给出公网访问地址（形如 `https://xxx.streamlit.app`）。
- 首次访问时应用会加载 `streamlit/models/` 下的模型并预热，稍等几秒即可。

## 四、部署到 Streamlit Cloud（备选方式：`streamlit/` 单独成库）

若希望部署包更干净，可把 `streamlit/` 文件夹本身作为**独立 Git 仓库**推送：

```bash
cd streamlit
git init
git add streamlit_app.py requirements.txt models/ 部署说明.md
git commit -m "feat: 地贫输血疗效 Hb 测算应用"
git remote add origin <你的仓库地址>
git push -u origin main
```

在 Streamlit Cloud 中：**Main file path = `streamlit_app.py`**（仓库根即是该文件夹）。

> 此方式下 Cloud 读取的是 `streamlit/requirements.txt`（同一份锁定版本），效果与上述整库部署完全一致。

## 五、关键注意事项（务必阅读）

### 1. 依赖版本必须与模型一致（最重要）
- 模型（`.pkl`）是用 **scikit-learn 1.3.2** 序列化的。
- `requirements.txt` 已锁定 `scikit-learn==1.3.2`。**请勿将其改为 `>=` 或更高版本**，
  否则云端会安装 1.8/1.9，导致 `No module named 'sklearn.ensemble._gb_losses'`
  或预测期 `AttributeError`，应用无法加载模型。
- 如需升级模型：必须在本机用**目标 scikit-learn 版本重新训练并导出** `.pkl`，
  同时同步更新 `requirements.txt`。

### 2. 中文显示
- 特征贡献（SHAP）图已改用 **Plotly** 绘制（浏览器端渲染），中文标签正常显示，
  **不依赖服务器字体**，因此 Streamlit Cloud 上不会出现方块。
- 应用其余中文界面由 Streamlit 自身渲染，也无需额外字体。

### 3. 模型与特征表不可缺失
- `streamlit/models/` 下必须同时包含 `.pkl` 与特征 `.csv`，否则应用会在加载时明确报错。
- 若更换模型，请保持特征 `.csv` 中存在「原始特征名称」列，且名称与模型输入特征完全一致。

### 4. 环境变量（可选）
- `STREAMLIT_MODEL_DIR`：自定义模型目录路径（优先级高于 `streamlit/models/`）。
- 一般无需设置；云端默认即可。

## 六、更新模型 / 重新部署

1. 在本机用与 `requirements.txt` 一致的 scikit-learn 版本重新训练并导出 `.pkl`，
   连同特征 `.csv` 放入 `streamlit/models/`（覆盖同名文件）。
2. 提交并推送：
   ```bash
   git add streamlit/models/
   git commit -m "chore: 更新模型"
   git push
   ```
3. 在 Streamlit Cloud 对应应用点击 **Redeploy** / **重启**，即可生效。

## 七、常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 加载模型失败 / `_gb_losses` | scikit-learn 版本与模型不一致 | 确认 `requirements.txt` 中 `scikit-learn==1.3.2`，重新部署 |
| 页面空白 / 依赖安装报错 | 根目录 `requirements.txt` 缺失或版本冲突 | 检查仓库根是否存在 `requirements.txt` 且版本正确 |
| 模型目录找不到 | `models/` 未随仓库提交 | 确认 `streamlit/models/` 已 `git add` 并推送 |
| SHAP 图中文乱码 | 仍在使用 matplotlib | 本版已改为 Plotly，无需处理；若自行改回 matplotlib 需安装中文字体 |
